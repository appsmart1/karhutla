Panduan Hosting GitHub Pages & Firebase Rules

Langkah 1: Setup Proyek Firebase

  1. Buka Firebase Console & buat Project baru.
  2. Aktifkan Build > Firestore Database (pilih lokasi terdekat: misal asia-southeast2 Jakarta).
  3. Aktifkan Build > Authentication > Tab Sign-in method > Aktifkan Anonymous.
  4. Di menu Project Settings > tambahkan Web App (`</>`) > salin objek firebaseConfig Anda.

Langkah 2: Aturan Keamanan Firestore (Rules)

Buka Firestore Database > Tab Rules > Salin aturan berikut agar form publik bisa membaca & menulis:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

Langkah 3: Deploy ke GitHub Pages

  1. Buat repositori baru di GitHub (misal: evaluasi-karhutla).
  2. Unggah file ini dan beri nama persis index.html di root repositori.
  3. Buka Settings > Pages > Pada bagian Branch pilih main / root > Save.
  4. Website Anda langsung aktif dan bebas dari masalah *cold start* atau batas kuota Google Spreadsheet!
